# Privacy policy

Automater performs automation locally on your Mac. It does not include analytics, advertising SDKs, accounts, cloud synchronization, or network telemetry.

Macros and settings are stored locally in Application Support. Local diagnostic entries retain only a timestamp, broad error category, and generic message; they exclude clicked coordinates, typed content, window titles, and app names. Diagnostics are never uploaded automatically.

Accessibility permission is used only to automate and inspect UI elements as requested by you. You can revoke it at any time in macOS Privacy & Security settings.
